# c2c-005 · 声音表情包工坊

Vue 3 + TypeScript + Vite 纯前端声音创作工具。支持长音频导入，在裁剪页获得最多 3 段、不超过 10 秒的候选片段推荐（仅依据声音能量与停顿，不做语音识别），可试听、选用后微调，再进入情绪分析、Canvas 封面、IndexedDB 本地作品集和系统文件分享流程。

## 候选片段推荐原理

为什么没有“只截最响的十秒”：响度高不代表内容完整——一声巨响可能只是磕碰或喷麦，最响的十秒也可能把一句话切成两半。推荐完全基于帧 RMS 能量曲线（25ms/帧）与停顿分布：

1. **自适应门限**：用能量分布的 20/90 分位估底噪和稳定响度，门限贴近底噪一侧，单处爆音不会抬高门限，连续讲话的小幅起伏也不会被误判成静音。
2. **停顿桥接**：≤0.18 秒的空隙视为句内换气并桥接，不切碎表达；>1 秒的停顿视为语句边界，候选绝不跨边界把两句互不相干的话硬拼成十秒；0.18~1 秒之间的停顿只有在两侧语音密度 ≥0.45 时才整体跨过（一句表达中间的长停顿会被保留）。
3. **候选成窗**：每个连通声段为种子贪心向两侧扩展，跨度始终 ≤10 秒；连续讲话超过 10 秒时在边界前 0.25 秒内寻找能量最低点下刀（换气点），不按整数秒生硬切；边界再外扩 ≤0.12 秒吞进安静留白，让起止点落在停顿处。
4. **排序**（与响度排序的区别）：出声密度 34% + 边缘落在停顿/端点 28% + 接近十秒的完整长度 22% + 相对响度 16%，再按噪声占比降权；整段平均/峰值能量最高的窗口若切在语句中央，排序会明显靠后。
5. **相近去重**：较短候选被较长候选覆盖 ≥60% 时只保留分高的，同一句话不会出现两张近似卡片。

边界情况：全静音/极低底噪不推荐并提示手动选段；<0.3 秒的孤立声响判为短促噪声；不足十秒的音频整段保留、不拼静音凑时长；无合适候选时裁剪滑块始终可用。推荐理由只陈述能量与停顿事实，不出现任何未做过的语义识别结果。

**推荐不修改原声音**：推荐结果只是时间标记；试听、选用、最终分析共用同一个 `cropper.crop()` 编码路径，所以听到的内容与保存的内容逐采样一致（见 `candidate-flow.integration.test.ts`）。

录音页内置 7 组合成对照声音（全静音 / 磕碰 / 短句 / 句内长停顿 / 两句长间隔 / 24 秒连续长讲含一处巨响 / 稀疏出声），可直接对比推荐边界与“只截最响十秒”的差异并载入裁剪页。`scripts/verify-demo.ts` 可打印每组声音的候选、WAV 采样数与时间标记的核对结果。

## 架构

- `src/core`：作品模型、特征归一化、情绪规则、封面预设、**候选推荐纯函数（`candidate-recommender.ts`）与对照声音合成（`demo-audio.ts`）**
- `src/ports`：录音、音频分析、**能量画像（profiler）与片段试听（preview）**、Canvas、仓储与分享接口
- `src/adapters`：MediaRecorder、Web Audio、**帧能量提取、HTMLAudio 试听**、Canvas、IndexedDB、Web Share 实现
- `src/ui`：Vue 阶段式工作流和原生 CSS

## 运行

```bash
npm install
npm run dev
npm run build
docker compose up --build
```

本地开发默认由 Vite 提供；Docker 部署访问 `http://localhost:8105`。浏览器录音在非 localhost 环境通常需要 HTTPS 和麦克风权限。

声音只保存在本机 IndexedDB，不会上传。生成的分享链接仅承载标题、情绪和封面配置，不包含原始音频；文件分享不受此限制。情绪识别是娱乐性启发式结果，不代表身份、性格或医学判断。
